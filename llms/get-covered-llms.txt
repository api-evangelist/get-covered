# Get Covered

> GetCovered, Inc. is a New York-based insurtech and property-risk platform (founded 2017)
> that consolidates renters insurance, security deposits, animal/ESA screening, vendor
> certificate-of-insurance compliance, procurement spend and review management into one
> system for multifamily property management portfolios. It reports 3M+ units live across
> 42 licensed states (NAIC #18224). Insurance services are offered through GetCovered
> Insurance Services, LLC.

## API surface

Get Covered has a live platform API but **no public machine-readable contract**.

- [Get Covered Platform API](https://api.getcoveredinsurance.com): the integration
  surface that syncs resident, lease, policy, vendor certificate and invoice data two-way
  at the lease level with property management systems, and powers the resident
  renters-insurance portal.
- [API reference (gated)](https://api.getcoveredinsurance.com/api-docs): returns HTTP 401
  with `WWW-Authenticate: Basic` — available only to partners Get Covered provisions.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, MCP server or A2A agent card is published.
  Probed on 2026-08-04: `/openapi.json`, `/openapi.yaml`, `/swagger.json`,
  `/v1/openapi.json`, `/api-docs/*`, `/graphql`, `/.well-known/agent-card.json`,
  `/.well-known/agent.json` — all 404 or 401.
- Integration access is arranged directly with Get Covered; there is no self-service
  developer portal, sandbox, or key issuance.

## Products

- Renters Insurance — HO4 policies, master policies, TLL programs, captive-ready framework
- Security Deposits — cash, surety and alternative deposits with 50-state compliance tracking
- Animal / Pet Screening — ESA verification, breed and weight enforcement, fraud detection
- Vendor Compliance — certificate-of-insurance management, credentialing, contracts
- Spend IQ — procurement, accounts payable, invoice validation, maverick-spend detection
- Reviews — review monitoring, drafted replies, reputation management
- GetHub — live portfolio data repository, dashboards, drill-down search, claims management
- Cora — conversational AI agent for resident inquiries, fee disputes and automated actions
